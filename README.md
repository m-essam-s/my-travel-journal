# My Travel Journal

This project uses a reusable Card component in React to display data dynamically. The Main component maps through a list of data and renders multiple cards.

## How to Run

1. Clone the repository
2. Run `my-travel-journal`
3. Run `npm install`
4. Run `npm run dev`

## Live Site

The live site can be found [here](https://messams-scrimba-my-travel-journal.netlify.app).
